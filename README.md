# AI 产品小红书评测合集

面向小红书发布的 AI 产品图文评测素材库。每篇内容采用 3:4 竖版轮播图，包含产品介绍、使用场景、优缺点和独立评分页。

## 内容结构

```text
reviews/
  <日期>-<产品名>/
    01.png ... 07.png       # 按发布顺序排列
    标题和笔记正文.txt       # 推荐标题、正文与话题标签
scripts/                    # 部分轮播图的生成脚本
```

## 发布约定

- 图片编号 `01`—`07` 即小红书上传顺序。
- 封面突出“本期评测产品”和产品名。
- 中间页面尽量使用产品界面、案例图和图案元素，避免连续纯文字页。
- 最后一页使用白色独立评分卡。
- 发布前重新核对价格、免费额度和功能限制。

## 说明

本仓库用于个人内容创作与整理。产品名称、Logo 和界面截图归各自权利人所有；评测结论仅代表内容创作时的体验与判断。
